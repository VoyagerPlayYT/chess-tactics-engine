Полноценная шахматная платформа с валидацией всех легальных правил FIDE (рокировки, взятие на проходе, превращение пешек, пат, мат, правило 50 ходов), встроенным AI-ботом на алгоритме Minimax с альфа-бета отсечением и позиционными таблицами ценности фигур (Piece-Square Tables), таймерами контроля времени (Blitz/Rapid), тактическим тренажёром этюдов и мультиплеером по локальной сети через WebSocket.

## Ключевой функционал

- **Полное соответствие правилам шахмат FIDE:** Строгая валидация ходов на стороне сервера через библиотеку `python-chess`.
- **Шахматный движок Minimax с альфа-бета отсечением:** 
  - 3 настраиваемых уровня сложности (Casual, Tactical, Master).
  - Сортировка ходов (Move Ordering) с приоритетом взятий для максимального коэффициента отсечения бесперспективных ветвей.
  - Оценка позиционного преимущества фигур в сантипешках (Centipawns) с визуализацией на вертикальной шкале преимущества (Evaluation Bar).
- **Синхронизация по локальной сети (WebSocket LAN Rooms):** Режим игры вдвоём по локальной сети без интернета. Создавайте комнаты и подключайтесь с любого планшета, телефона или ПК в доме.
- **Тренажер тактических этюдов:** Встроенная база тактических задач в SQLite (мат в 1 ход, королевские вилки, жертвы ферзя, линейные удары) с мгновенной валидацией решения.
- **Таймеры контроля времени:** Часы с отсчетом секунд для белых и черных с переключением при каждом ходе.
- **Архив партий в SQLite:** Сохранение PGN-нотации, результатов и статистики сыгранных матчей.

## Запуск в 1 клик

```cmd
start.bat
```
Скрипт установит `python-chess`, `fastapi`, `uvicorn` и откроет шахматный интерфейс на `http://localhost:8013`.
